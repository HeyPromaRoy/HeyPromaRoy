## 📂 Featured Research & Publications

### [Structural Silence: When AI Infrastructure Fails Speakers of Underrepresented Languages](https://doi.org/10.2139/ssrn.6522858)
*SSRN Electronic Journal Preprint (2026) | Co-authored with Avijit Roy*
This research examines structural inequalities in modern AI infrastructure affecting underrepresented languages, using Bengali as a case study. It explores web presence disparities, tokenization inefficiencies, and argues for offline-first design as equity infrastructure.

## ⚙️ Key Engineering Projects

### 🛡 [Security Audit of Rust-Based E-Voting System](https://github.com/HeyPromaRoy/secure-systems-evoting-audit)
Conducted a comprehensive security audit of a Rust-based electronic voting platform. Applied STRIDE threat modeling, OWASP Top 10 mapping, static analysis, and runtime fault injection to identify vulnerabilities across authentication, access control, and cryptography.

### 🔐 [Threshold ElGamal Encryption](https://github.com/HeyPromaRoy/Threshold-ELGamal)
Implemented a threshold cryptography system in Rust featuring Distributed Key Generation (DKG), threshold decryption, Zero-Knowledge Proofs, and multi-party secure collaboration.

### 🌡 [Smart Thermostat — Secure CLI HVAC Prototype](https://github.com/HeyPromaRoy/SmartThermostat)
Built a secure, role-based smart thermostat CLI with HVAC simulation. Implemented Argon2id password hashing, RBAC, session management, hardened SQLite storage, and a tamper-evident integrity check verified at startup.
