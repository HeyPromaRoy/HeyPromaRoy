## Featured Academic Projects

### Security Audit of a Rust-Based E-Voting System
*Secure Systems Engineering — CCNY*

- Conducted a comprehensive security audit of a Rust-based electronic voting system.
- Evaluated both original and adversarially modified codebases.
- Identified vulnerabilities across authentication, access control, cryptography, data privacy, availability, and build integrity.
- Applied STRIDE threat modeling, OWASP Top 10 and CWE mapping, static analysis, runtime fault injection, and build pipeline inspection.
- Proposed concrete mitigation strategies aligned with secure-by-design and responsible disclosure principles.

---

### Smart Thermostat — Secure CLI HVAC Prototype (Rust)

- Built a secure, role-based smart thermostat CLI with HVAC simulation and energy tracking.
- Implemented Argon2id password hashing, role-based access control, and session management with hashed tokens.
- Designed account and session lockout mechanisms and audit logging.
- Used hardened SQLite storage with secure PRAGMA settings.
- Added a tamper-evident integrity check (INTEGRITY.sha256) verified at startup.
- Developed integration tests covering authentication, database, and system logic.
